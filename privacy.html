CIA Backup Privacy Policy

CIA Backup is a personal-use backup application operated by its owner.

It uses the Google Drive API to create and manage backup files in the owner's Google Drive account.

Production backups are designed to be encrypted locally using Restic before upload.

OAuth credentials are stored on the owner's server. The application does not sell user data, serve ads, or share backup contents with third parties.

Access can be revoked through Google Account settings.
